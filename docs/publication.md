# Before making this repository public

This is a private development release. Publication requires a separate owner decision.

- Independently review source, tests, documentation, current files **and Git history**.
- Keep deployment config, original handoff/provenance, tokens, endpoint URLs, account
  exports, private server identities, raw evidence and notification payloads out of Git.
- All examples/fixtures must remain synthetic. Scan release artifacts and metadata.
- Reconfirm current API contracts, permissions and limitations. Do not describe
  Alpha access, adaptive metrics or fake canary results as live guarantees.
- Resolve blocking review findings and reproduce offline/Linux acceptance tests.
- Confirm license choice and a usable private vulnerability-reporting contact.
- Preserve explicit unknown coverage and the statement that this is not a spending cap.
- No workflows or paid CI are enabled. Adding automation needs separate review.

Independent agent reviews are useful scrutiny, not a third-party security certification.
No production readiness claim should exceed the evidence in `handoff-status.json`.
