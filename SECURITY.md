# Security policy

Do not put credentials, account exports, deployment configuration, private endpoints
or customer data in Git or issue reports. Use synthetic reproductions. For a
vulnerability, contact the repository owner privately through GitHub before disclosure.
Do not include secrets in that message.

No third-party security audit or production safety certification is claimed. Read
[the threat model](docs/threat-model.md) and [capabilities](docs/capabilities.md)
before use. Keep the repository private until the publication checklist is complete.
