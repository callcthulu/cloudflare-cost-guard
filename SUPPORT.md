# Support

Start with [getting started](docs/getting-started.md), [configuration](docs/configuration.md),
[the runbook](docs/runbook.md) and [troubleshooting](docs/troubleshooting.md).
[Capabilities](docs/capabilities.md) describes missing and approximate data.

Use [GitHub Issues](https://github.com/callcthulu/cloudflare-cost-guard/issues) for
ordinary bugs, questions and focused feature requests. Include the commit,
Python/OS version, command, expected and actual behavior, exit code and the smallest
synthetic reproduction. Use the issue templates where applicable.

Keep tokens, actual account/zone/resource IDs, private URLs, configuration, SQLite
state, exports, raw logs and notification payloads out of reports. Reproduce with
invented data instead of attaching a private deployment. Report vulnerabilities
through [SECURITY.md](SECURITY.md).

Maintainer help is voluntary, with no guaranteed response time or commercial
support commitment. Cloudflare billing disputes and account access belong with
Cloudflare; host administration belongs with the host owner.
