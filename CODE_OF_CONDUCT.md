# Code of conduct

Treat people with respect in this repository's issues, pull requests, reviews and
other project spaces. Challenge ideas and evidence without attacking people.
Accept constructive feedback and respect others' privacy.

Harassment, threats, discriminatory abuse, sexual harassment, doxxing, deliberate
disruption and publishing another person's private information are unacceptable.
Do not post credentials or private deployment data, even as part of a complaint.

Maintainers may edit or remove content, close or lock conversations, reject
contributions or restrict participation to protect the project and its contributors.
They should apply these expectations consistently and consider the context and
severity of the behavior.

For nonsensitive conduct concerns, ask for maintainer attention in the affected
conversation. For sensitive reports, use the content menu's **Report content**
option and **Report to repository admins** if GitHub offers it. Otherwise, or for
abuse involving a maintainer, use
[GitHub Support's abuse report form](https://support.github.com/contact/report-abuse?category=report-abuse&report=other&report_type=unspecified).
This sends the report to GitHub Support, not a private maintainer inbox.
See [GitHub's reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
for availability and steps. Do not put sensitive details in a public issue while
seeking a contact. Software vulnerabilities follow [SECURITY.md](SECURITY.md).
